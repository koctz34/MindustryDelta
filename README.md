# DELTA Client
A client specifically designed for the Delta server.

Key changes from the standard version of Mindustry:
- Updated canvases:
  - They can now be any color
  - Brush size added
  - Synchronization works with vanilla clients
  - Custom pallets
  - New tools
- Modified network protocols:
  - Increased maximum packet size
  - Client synchronization with vanilla clients
- Down restrictions:
  - Map size unlimited
  - Max schematic size now 512
  - instantBuild now working on delta-servers
- World news in main menu
